Read [the owning workflow](../../../docs/jira-workflow.md) before starting or
resuming work and before committing. Inspect live Jira scope, hierarchy and
prerequisites, local changes and local/remote refs. Explicit instructions take
precedence over saved context; the epic execution order may supply an unambiguous
next ready child. Ask only when attribution or epic selection remains ambiguous.

Use one shared epic branch; never create child, author or publication branches.
Load the session's own verified context; never borrow another session's active
item. Review staged scope yourself, then use the guarded commit command. A key
check does not establish semantic correctness, Jira ingestion or completion.
Preserve author identity, unrelated changes, manual database ownership and release
approvals. Report epic, branch, item-to-commit mapping and outstanding steps.
